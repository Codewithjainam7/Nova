# Objective

Build NOVA's complete Vision Engine.

The Vision Engine enables NOVA to understand screens, applications, windows, screenshots, PDFs, images, and visual interfaces to support intelligent automation and verification.

Every visual understanding result must include a confidence score and be verifiable.
