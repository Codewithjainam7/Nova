# Objective

Build NOVA's signature Dynamic Island interface.

The Dynamic Island is the primary interaction layer between the user and NOVA. It should feel as smooth and premium as Apple's Dynamic Island while remaining unique to NOVA.

The island must stay centered at the top of the screen and intelligently expand, collapse, animate, and display the current state of NOVA.
