# Objective

Build NOVA's Email & Personal Communication Agent.

The Email Agent enables NOVA to intelligently compose, read, summarize, search, organize, reply to, and send emails while integrating with calendars, reminders, contacts, and notifications.

Every communication action must be verified before reporting success.

Every email send operation must require explicit user confirmation unless explicitly allowed by the user.
