# Objective

Build NOVA's modern AI chat experience.

The Chat System is the primary workspace for interacting with NOVA. It must support streaming AI responses, multiple conversations, multimodal inputs, file uploads, markdown rendering, code blocks, citations, voice interaction, and long-term conversation history.

Every conversation should integrate with the Memory Engine and Planner.
